# **App Name**: CryptoU

## Core Features:

- Secure Authentication: User authentication using Firebase Authentication to secure access to the platform's content.
- Video Player: A video player for streaming the crypto education videos, with controls for playback, volume, and full-screen mode.
- Personalized Dashboard: Display user-specific information, active subscriptions and progress tracking within courses.
- Subscription Management: Offer users subscription options via Stripe.
- Admin Panel: Admin dashboard to allow content upload and management, as well as user subscription overview.

## Style Guidelines:

- Primary color: Deep indigo (#4B0082), reminiscent of intellect and the potential of technology.
- Background color: Very light lavender (#F0F8FF). This choice complements the deep indigo while keeping a modern and airy aesthetic suitable for prolonged educational sessions.
- Accent color: Bright orange (#FFA500) for interactive elements. The choice will drive the user toward key actions without overpowering the rest of the composition.
- Headline font: 'Playfair', serif, to suggest quality of information. Body font: 'PT Sans', sans-serif, so that the user experience will feel familiar.
- Use simple, geometric icons for navigation and video controls.
- A clean, grid-based layout will provide an organized learning experience
- Subtle transitions when navigating between lessons and modules.
